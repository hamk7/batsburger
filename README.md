# BAT'S BURGER – Konzept-Webseite

Eine rein statische, klickbare Demo, um die Idee für eine neue BAT'S-BURGER-Kundenwebseite zu präsentieren.

## Was funktioniert in der Demo?

- responsive Darstellung für PC, Mac, iPhone und iPad
- Startseite mit modernem BAT'S-BURGER-Look
- Bestseller und Speisekarte
- Kategorien filtern
- Produktdetails öffnen
- Beispiel-Extras auswählen
- Artikel in einen Demo-Warenkorb legen
- Lieferung / Abholung auswählen
- PLZ-Feld und Mindestbestellwert als Konzept darstellen
- FAQ, Standort und Öffnungszeiten

## Was ist ausdrücklich NICHT echt?

- keine Datenbank
- keine Benutzerkonten
- keine echte Bestellung
- keine Zahlung
- keine Verbindung zur Kasse
- keine echten Liefergebietsprüfungen
- keine Admin-Oberfläche

Das ist absichtlich so: Die Seite soll zuerst zeigen, wie das zukünftige Kundenerlebnis aussehen könnte.

## Lokal öffnen

Einfach `index.html` doppelklicken. Für die vollständige Darstellung werden die Beispiel-Foodfotos und Google Fonts aus dem Internet geladen.

## Auf GitHub Pages veröffentlichen

1. Neues GitHub-Repository erstellen, z. B. `bats-burger-konzept`.
2. `index.html`, `styles.css`, `script.js` und `README.md` in das Repository hochladen.
3. In GitHub zu **Settings → Pages** gehen.
4. Unter **Build and deployment** bei Source **Deploy from a branch** auswählen.
5. Branch **main**, Ordner **/(root)** wählen und speichern.
6. Nach kurzer Zeit zeigt GitHub die öffentliche Demo-URL an.

## Hinweis zu Inhalten

Produkte und Preise wurden für die Präsentation an der aktuell öffentlich sichtbaren Speisekarte orientiert. Öffnungszeiten, Aussagen zu halal/helal, Preise, Bilder, Lieferregeln und rechtliche Inhalte müssen vor einer echten Veröffentlichung vom Betreiber geprüft werden.

Die Foodfotos sind austauschbare Konzeptbilder und keine zugesicherten Originalfotos von BAT'S BURGER.
